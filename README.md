## 📖 Project Overview

This project is a comprehensive Power BI dashboard designed to analyze the global job market for data professionals in 2024. It provides a high-level overview of salary trends, job volume, and key correlations between roles, while allowing users to deep-dive into specific job titles to understand granular details like Work From Home (WFH) availability and degree requirements.

The dashboard aims to help job seekers and recruiters understand the current landscape of data careers, including **Data Analysts, Data Scientists, and Data Engineers.**

## 🌟 Key Features & Interactivity

### 🔍 **Smart Drill-Through Functionality**
A core feature of this dashboard is the **Job Title Drill Through**. 
- On the main page, users can select a specific job category (e.g., *Data Analyst* or *Data Engineer*) from the summary table.
- Using the "Drill Through" button, the dashboard navigates to a dedicated details page that filters all data specifically for that role.
- This allows for a seamless transition from broad market trends to specific role profiling.

### 📊 **Visual Insights**
- **Market Trends:** A line chart tracking the volume of job postings throughout 2024, identifying seasonal peaks and drops.
- **Salary Analysis:** - Comparison of Median Yearly vs. Hourly salaries.
  - "Salary Star Rating" to quickly gauge compensation attractiveness.
  - Scatter plot analysis correlating Hourly rates with Yearly packages across different roles.
- **Geographic Distribution:** A global map visualization showing job density across different continents.
- **Role Requirements:** Donut charts breaking down:
  - Work From Home (WFH) percentage.
  - "No Degree Mentioned" percentage (barrier to entry analysis).
  - Health Insurance availability.

## 💡 Key Insights Derived

Based on the data visualized in this dashboard:
1.  **Salary Hierarchy:** Senior Data Scientists and Engineers command the highest median salaries (approx. $150k+), while Data Analysts average around $90k.
2.  **Job Platforms:** LinkedIn remains the dominant platform for data job postings, significantly outpacing competitors like ZipRecruiter and Indeed.
3.  **Market Trend:** There was a noticeable downward trend in job postings towards the latter half of 2024 (Nov), suggesting a market cooling or seasonal hiring freeze.
4.  **Barrier to Entry:** Approximately **38%** of Data Analyst job postings do not explicitly mention a degree requirement, indicating a shift towards skills-based hiring.

## 🛠️ Tech Stack & Process

* **Tool:** Microsoft Power BI
* **Data Transformation:** Power Query (ETL)
* **Calculations:** DAX (Data Analysis Expressions) for measures like Median Salary, Job Counts, and ratios.
* **Visualization:** Custom gauge charts, scatter plots, and map visuals.

## 🚀 How to Use This File

1.  Download the `.pbix` file from this repository.
2.  Open with **Power BI Desktop**.
3.  Interact with the slicers on the top (Job Title, Country) to filter the data.
4.  **Try the Drill Through:** Right-click a job title in the bottom-right table of the main page $\rightarrow$ Drill Through $\rightarrow$ Job Details.
